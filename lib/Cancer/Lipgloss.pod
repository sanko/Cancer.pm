=encoding utf8

=head1 NAME

Cancer::Lipgloss - High-level terminal styling library for Perl

=head1 SYNOPSIS

    use Cancer::Lipgloss qw[
        NewStyle Color NoColor
        NormalBorder RoundedBorder
        JoinHorizontal JoinVertical
        Left Center Right Top Bottom
        PlaceHorizontal PlaceVertical
        string_width width height
    ];

    # Style text
    my $styled = NewStyle()
        ->bold(1)
        ->foreground([255, 100, 50])
        ->padding_left(2)
        ->render("Hello, world!");

    # Join two multi-line strings side by side
    my $joined = JoinHorizontal(Top, $left, $right);

    # Place text in a fixed-width box
    my $centered = PlaceHorizontal(40, Center, "centered");

=head1 DESCRIPTION

Cancer::Lipgloss is a Perl port of L<https://github.com/charmbracelet/lipgloss>, a high-level terminal styling library.
It provides a fluent API for building styled text with foreground/background colors, bold, italic, borders, padding,
margins, alignment, and more.

=head1 FUNCTIONS

=head2 NewStyle()

Returns a new L<Cancer::Lipgloss::Style> object. All methods return a new clone (chaining is safe).

=head2 Color($hex_or_string)

Parses a color from a string. Supports C<#RRGGBB>, C<#RGB>, C<rgb:RRRR/GGGG/BBBB>, and similar formats. Returns an
L<Cancer::Lipgloss::RGBColor>.

=head2 NoColor()

Returns a L<Cancer::Lipgloss::NoColor> object (represents no color / transparent).

=head2 NormalBorder(), RoundedBorder(), BlockBorder(), ThickBorder(), DoubleBorder(), HiddenBorder(), MarkdownBorder(), ASCIIBorder(), NoBorder(), OuterHalfBlockBorder(), InnerHalfBlockBorder()

Return predefined L<Cancer::Lipgloss::Border> objects.

=head2 JoinHorizontal($position, @strings)

Joins multiple multi-line strings horizontally. C<$position> is one of C<Left>, C<Center>, or C<Right> and controls
vertical alignment.

=head2 JoinVertical($position, @strings)

Joins multiple strings vertically. C<$position> is one of C<Left>, C<Center>, or C<Right> and controls horizontal
alignment.

=head2 PlaceHorizontal($width, $position, $string, @options)

Places a string in a horizontal box of the given width. C<$position> controls horizontal placement (C<Left>, C<Center>,
C<Right>).

=head2 PlaceVertical($height, $position, $string, @options)

Places a string in a vertical box of the given height. C<$position> controls vertical placement (C<Top>, C<Center>,
C<Bottom>).

=head2 Place($width, $height, $hpos, $vpos, $string, @options)

Places a string in a box of the given dimensions; combines both placements.

The optional trailing arguments to the place functions are whitespace options: pass C<WithWhitespaceChars($chars)> to
fill gaps with specific characters or C<WithWhitespaceStyle($style)> to style the filler.

=head2 LightDark($is_dark)

Returns a coderef that picks between a light and dark color: C<< my $pick = LightDark(1); $pick->( $light, $dark ); >>.

=head2 AdaptiveColor(light => $c1, dark => $c2)

Picks between two colors based on C<has_dark_background>.

=head2 Complete($profile)

Returns a coderef selecting among three colors for the given profile name (C<ANSI>, C<ANSI256>, or C<TrueColor>).

=head2 has_dark_background( ), query_terminal_bg( )

Query the terminal for its background color; C<query_terminal_bg> returns the parsed RGB triple (or undef on
timeout/failure), C<has_dark_background> returns true when it is a dark color.

=head2 StyleRanges($string, @ranges)

Renders each byte range of C<$string> with its range's style.

=head2 NewRange($start, $end, $style)

Creates a range hashref for C<StyleRanges>.

=head2 StyleRunes($string, \@indices, $matched_style, $unmatched_style)

Styles individual runes (characters) of a string at the given indices.

=head2 blend_1d($steps, @stops), blend_2d($width, $height, $angle, @stops)

Gradient helpers re-exported from L<Cancer::Color::Blend>.

=head2 Print(@strings), Println(@strings), Printf($fmt, @args)

Write to STDOUT with automatic color downsampling for the detected terminal profile; C<Println> appends a newline. They
return the number of bytes written.

=head2 Fprint($fh, ...), Fprintln($fh, ...), Fprintf($fh, $fmt, ...)

The same, writing to a filehandle.

=head2 Sprint(...), Sprintln(...), Sprintf(...)

The same, returning the string instead of printing.

=head2 NewCanvas(%args), NewLayer($content, @layers), NewLayerHit(%args), NewCompositor(@layers)

Constructors for layered rendering; see L<Cancer::Lipgloss::Canvas>, L<Cancer::Lipgloss::Layer>, and
L<Cancer::Lipgloss::Compositor>.

=head2 Black(), Red(), Green(), Yellow(), Blue(), Magenta(), Cyan(), White(), BrightBlack(), BrightRed(), BrightGreen(), BrightYellow(), BrightBlue(), BrightMagenta(), BrightCyan(), BrightWhite()

The 16 standard ANSI colors as color objects.

=head2 UnderlineNone, UnderlineSingle, UnderlineDouble, UnderlineCurly, UnderlineDotted, UnderlineDashed

Underline style constants for C<< ->underline_style($n) >>.

=head2 NoTabConversion

Constant disabling tab conversion during render.

=head2 NBSP

The non-breaking space character used by some styles.

=head2 string_width($string)

Returns the visual width of a string (ANSI escape codes stripped).

=head2 width($string)

Alias for C<string_width>.

=head2 height($string)

Returns the number of lines in a string.

=head2 LEFT, CENTER, RIGHT, TOP, BOTTOM

Position constants for alignment functions.

=head1 STYLE PROPERTIES

Style objects support these setters (each returns a clone):

    ->bold($bool)              ->italic($bool)
    ->underline($bool)         ->strikethrough($bool)
    ->foreground($color)       ->background($color)
    ->width($n)                ->height($n)
    ->padding_top($n)          ->padding_right($n)
    ->padding_bottom($n)       ->padding_left($n)
    ->margin_top($n)           ->margin_right($n)
    ->margin_bottom($n)        ->margin_left($n)
    ->align_horizontal($pos)   ->align_vertical($pos)
    ->align($pos)              ->underline_style($n)
    ->border_style($border)    ->border_top($bool)
    ->border_right($bool)      ->border_bottom($bool)
    ->border_left($bool)
    ->hyperlink($url)          ->tab_width($n)
    ->max_width($n)            ->max_height($n)
    ->set_string($str)         ->inherit($base_style)

Each setter has a corresponding C<get_*> getter. C<align> sets both horizontal and vertical alignment at once;
C<set_string> stores content for later rendering via stringification.

Colors can be passed as:

    # RGBColor object
    $style->foreground(Color("#FF8000"));

    # Arrayref [R, G, B] (0-255)
    $style->foreground([255, 128, 0]);

=head1 OBJECTS

=head2 Cancer::Lipgloss::Style

The main style object. Created by C<NewStyle()>.

=head2 Cancer::Lipgloss::RGBColor

Represents an RGB color. Has C<->RGBA()> returning (R, G, B, A) and C<->is_no_color()> returning false.

=head2 Cancer::Lipgloss::NoColor

Represents absence of color. C<->is_no_color()> returns true.

=head2 Cancer::Lipgloss::BasicColor

Represents one of the 16 ANSI basic colors.

=head2 Cancer::Lipgloss::IndexedColor

Represents one of the 256 indexed terminal colors.

=head2 Cancer::Lipgloss::Border

A hashref with keys C<top>, C<bottom>, C<left>, C<right>, C<top_left>, C<top_right>, C<bottom_left>, C<bottom_right>,
C<middle>, C<middle_left>, C<middle_right>, C<middle_top>, C<middle_bottom>.
